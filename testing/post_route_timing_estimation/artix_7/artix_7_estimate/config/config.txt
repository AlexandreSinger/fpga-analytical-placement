# the post-routing timing estimate and the legality estimate of that

# test suite
# (fpga-analytical-placement/testing/test_suites/artix_7_ap): the VTR
# circuits on Artix-7-like devices of the 7-series architecture, routed at
# the physical channel width of the chip (190).
#
# See ../../README.md for how to run this experiment.

# Path to directory of circuits to use
circuits_dir=/shared/singera8/7series_blifs

# Path to directory of architectures to use
archs_dir=arch/xilinx

circuit_constraint_list_add=(stereovision0.blif, device=XC7A200T-like)
circuit_constraint_list_add=(stereovision1.blif, device=XC7A75T-like)

# Read in the final flat placement of the routed task (copied into this task's

# Parse info and how to parse

# Pass requirements
pass_requirements_file=pass_requirements_ap_global_place.txt

# Read in the flat placement and stop after global placement (--global_place),
# which skips the global placer, so only the estimates of the read-in flat
# placement are made. Writes the estimated timing graph, wire usage, and
# legality echo files.
# The router options are kept the same as the routed task, since the place
# delay model used by the estimate is built from the router lookahead.
script_params=-starting_stage vpr --route_chan_width 190 --seed 1 --global_place --echo_file timing_graph.ap_post_routing_estimate.echo wire_usage.ap_post_routing_estimate.echo legality.ap_estimate.echo
